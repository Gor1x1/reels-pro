# Reels Pro

Рабочий репозиторий: **`~/Developer/reels-pro`** — там код, стили и пайплайн.
Ролик описывается спецификацией `src/spec.json`, стиль переключается одной строкой.

## Железные правила

1. **Сначала анализ, потом монтаж.** `ffprobe` + кадры каждые 1–2 с + транскрипт. Не резать вслепую.
2. **Показать план по таймкодам** до сборки.
3. **Эмодзи не использовать.** Они удешевляют картинку. Во всех стилях выключены — не включать без прямой просьбы.
4. **Проверять результат программно**, а не на глаз: диаризация финала, уровни звука, кадры на артефакты.

## Отделить речь автора от закадровой подсказки

Три независимые проверки, совпадение = уверенность:
1. **Диаризация** ElevenLabs Scribe (`diarize=true`) — подсказка идёт первой, автор повторяет.
2. **Громкость** — подсказка тише на 10–12 dB (звучит из динамика).
3. **Губы на кадре** — вырезать кадр в момент реплики: у подсказки рот закрыт. Решающий тест.

Дальше: EDL только из сегментов автора, выкинуть фальстарты (та же фраза, повторённая полнее)
и техническую болтовню в конце. Точные границы — `silencedetect` с порогом ВЫШЕ уровня подсказки
(например `-34dB`): Scribe часто включает в слово хвост тишины.

## Замена фона — и главная ловушка

```bash
python ~/Developer/reels-pro/pipeline/matte.py \
  --video raw.mp4 --bg bg.png --out comp.mp4 \
  --grade "0.82,0.76,0.66" --exposure 0.92
```

**Не использовать ffmpeg `chromakey`/`colorkey`** на любительском зелёном фоне — рвёт лицо,
оставляет ореолы. Проверено, даёт брак.

⚠️ **Ловушка, на которой уже обожглись:** нельзя уменьшать человека (`--scale < 1`), если в
исходнике он обрезан краем кадра. Срез руки уезжает внутрь кадра — получается «обрубок»,
и весь ролик выглядит дёшево. Режим `--fit auto` (по умолчанию) измеряет касание альфы к краям
и сам поднимает масштаб:

```
разведка кадра: касание краёв left, right, bottom
  ! человек обрезан слева и справа — масштаб 0.88 показал бы срез, поднимаю до 1.0
```

Чтобы показать больше фона — двигать фон (`--bg-zoom`, `--bg-dx`), а не уменьшать человека.

Ключи: `--despill` (зелёный отлив), `--shrink` (кромка), `--lightwrap` (свет фона на краях),
`--feather` (мягкое затухание у срезанных краёв), `--grade`/`--exposure` (свет под фон).

## Стили

| id | Когда |
|---|---|
| `warm-studio` | тёплый интерьер, спокойный премиум |
| `bold-orange` | высокая динамика, крупные капсы, хайп |
| `clean-minimal` | деловой тон, без скобок/боке/бейджа |
| `neon-night` | тёмный кадр, свечение, техно и AI |

Стиль задаёт палитру, тип субтитров, размер титров, декор и силу зумов — код сцен не меняется.
Предпросмотр всех сразу: композиции `Style-*` в `npx remotion studio`.

## Спецификация

```jsonc
{
  "style": "warm-studio",
  "lang": "hy",                      // ru | hy | en — определяет шрифт
  "video": "main.mp4", "background": "bg.png", "music": "music.mp3",
  "brand": { "badge": "GTH", "name": "ԳՈՌ", "role": "GTH LAB" },
  "scenes": [
    { "type": "hook",    "dur": 72, "title": "GTH LAB", "subtitle": "AI AGENT LAB" },
    { "type": "speaker", "dur": 900,
      "zooms":   [[0,1.04],[5.6,1.1],[20.3,1.12]],
      "punches": [{ "at": 6.0, "dur": 62, "line1": "GTH", "line2": "LAB" }],
      "nameAt": 24.0 },
    { "type": "broll",   "dur": 90, "src": "screen.mp4", "isVideo": true, "label": "DEMO" },
    { "type": "cta",     "dur": 90, "line1": "ՀԵՏԵՎԻՐ", "line2": "ԱԼԻՔԻՆ", "button": "GTH LAB" }
  ]
}
```

Тексты титров брать **из речи автора** — гарантия правильного языка (особенно армянского).
Зумы привязывать к смыслу: приближение на выводе и призыве, отъезд на перечислении. 5–8 на 30 с.

## Звук

1. **ElevenLabs Audio Isolation** — убирает фоновые голоса и шум комнаты (шумовой порог падает
   на ~18 dB, речь не страдает).
2. Мастеринг: `highpass=f=80, acompressor=threshold=-18dB:ratio=3, equalizer=f=3000:g=2,
   loudnorm=I=-14:TP=-1.5`.
3. Музыка 7–8 % громкости, не выше.

## Субтитры

Пословная разметка из Scribe → блоки по 5–6 слов (разрыв >0.55 с или конец предложения = новый блок)
→ `src/captions.json` формата `[{start, end, words:[{t,s,e}]}]`.
В стилях `warm-studio` и `neon-night` — караоке-подсветка: сказанное белым, будущее приглушено.

## Шрифты

`Montserrat-Black` (лат+кир) · `NotoArm` (лат+арм) · `Anton` (латиница).
Системные SF Pro / Georgia армянский НЕ рендерят, Anton не знает кириллицы. Выбор — по полю `lang`.

## Контроль качества

- финал через Scribe с диаризацией → должен быть **один** говорящий;
- транскрипт финала читается связно, без обрывов;
- пик не выше −3 dB, RMS около −18;
- 4–5 кадров глазами: артефакты матирования, ореолы, **срезы рук**, перекрытия текста;
- формат 720×1280 (или 1080×1920), 30 fps, субтитры вне зоны UI площадки.

## Грабли Remotion

- не читает mp4 с mp3-звуком внутри («Assertion failed») — перекодировать в h264+aac;
- `fade` на одиночном PNG не работает: зациклить `-loop 1 -framerate 30 -t <dur>`;
- проверка кадра без полного рендера: `npx remotion still <id> --scale=0.5 --frame=N out.png`.

Связано: скилл `lipsync` (синхронизация губ), правило хук-роликов в
`~/Documents/wb-notes/wiki/Бизнес/Контент-завод-Регламент-Видеомонтаж-Хуки.md`.
