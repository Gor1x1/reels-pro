# УСТАНОВКА агента «монтаж» на новой машине

Агент состоит из двух частей:

| Часть | Что это | Где в репозитории |
|---|---|---|
| **Голова** | агент Claude Code `монтаж` + 9 отделов `montaj-*` | `.claude/agents/` |
| **Руки** | движок reels-pro: 44 скрипта конвейера, Remotion-рендер, стили, конфиги | корень репозитория |

Без движка агент не работает: он не монтирует «руками в окне», а гоняет скрипты.
Поэтому передаётся репозиторием, а не текстовым файлом.

## 1. Что нужно на машине

Всё ставится **без прав администратора**.

| Инструмент | Версия | Как поставить |
|---|---|---|
| Windows | 10/11 | — |
| Git | любой свежий | `winget install Git.Git --scope user` |
| GitHub CLI | любой | `winget install GitHub.cli --scope user`, затем `gh auth login` |
| Python | 3.12 | `winget install Python.Python.3.12 --scope user` |
| Node.js | 24 (zip, без установщика) | ставит `setup.ps1` в `C:\Ferma\tools\node` |
| ffmpeg | 7+ (у нас 9.0 full) | `winget install Gyan.FFmpeg --scope user` |
| Claude Code | свежий | https://claude.com/claude-code |
| Плагины Claude Code | `ffmpeg-skill`, `hyperframes` | в Claude Code: `/plugin install ffmpeg-skill@ffmpeg-skill`, `/plugin install hyperframes@hyperframes` |

Видеокарта не нужна: всё считается на процессоре (torch CPU, faster-whisper CPU).
Нужны 16+ ГБ памяти и 30+ ГБ места: рабочие прогоны (`runs/`) растут быстро.

## 2. Клонирование — строго в эту папку

```powershell
git clone <ссылка на репозиторий> C:\Ferma\factory\reels-pro
cd C:\Ferma\factory\reels-pro
```

Путь `C:\Ferma\factory\reels-pro` зашит в скрипты конвейера и в агентов.
Другое место потребует правки путей в `pipeline\*.py` и `.claude\agents\*.md`.

## 3. Зависимости

```powershell
.\setup.ps1
```

Скрипт ставит node, `npm install`, torch CPU и питон-библиотеки, качает модели.
Если он остановился с просьбой перезапустить терминал — перезапусти и прогони ещё раз.

Полный список питон-библиотек, если ставить руками:

```powershell
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install faster-whisper ctranslate2 librosa soundfile numpy scipy onnxruntime opencv-python pillow mediapipe pyjianyingdraft python-dotenv requests rich tqdm yt-dlp imageio huggingface_hub piper-tts
```

Проверка:

```powershell
python -c "import faster_whisper, librosa, soundfile, onnxruntime, cv2, torch; print('ок')"
ffmpeg -version
node --version
```

## 4. Ключи

```powershell
Copy-Item .env.example .env
```

Открой `.env` и вставь свои ключи Pexels и Pixabay (бесплатные, нужны для вставок со стоков).
Ключ ElevenLabs не обязателен. **Файл `.env` в git не попадает — не пересылай его.**

## 5. Агенты

Агенты лежат в `.claude/agents/` и подхватываются, когда Claude Code открыт в папке
репозитория. Чтобы звать агента из любой папки, скопируй их в пользовательскую папку:

```powershell
Copy-Item .claude\agents\*.md "$env:USERPROFILE\.claude\agents\" -Force
```

Файлы агентов должны оставаться с переводами строк LF (`.gitattributes` это держит):
при CRLF и двоеточии в описании агент молча не загружается.

После копирования — **новый чат** в Claude Code: реестр агентов читается при старте.

## 6. Библиотеки владельца

| Что | Где в репозитории | Кто использует |
|---|---|---|
| Фоны (12 картинок) | `fony/` | отдел `montaj-fon` по каталогу `config/fony-vladelca.md` |
| Каталог стилей (15 стилей + картинки) | `stili/` | все отделы, выбор стиля в `montaj-smysl` |
| Вкус владельца | `config/vkus-vladelca.md` | все |
| Словарь исправлений распознавания | `config/fix-words.json` | `transcribe.py`, `align.py` |

Хочешь свои фоны — положи картинки в `fony/` и опиши их в `config/fony-vladelca.md`
по образцу (номер, что на картинке, какому настроению речи подходит).

## 7. Первый запуск

```powershell
.\build.ps1 -Still -Frame 30          # пробный кадр из студии Remotion
python pipeline\ochered.py status     # очередь тяжёлых работ свободна?
```

Если `remotion.exe` блокирует Smart App Control — кадры снимаются обходом
`pipeline\snap.mjs` через системный Chrome; агент это знает.

Потом в Claude Code, в новом чате:

> смонтируй C:\путь\к\видео.mp4

Агент сам выберет режим по материалу (рилс, урок, шорты из эфира, сборка фильма,
доработка готового, монтаж в чужой программе), покажет замысел и соберёт ролик.
Готовый файл, лист кадров и отчёт кладутся в `runs\<дата>\<имя>\GOTOV\`.

## 8. Законы движка

- **Одна тяжёлая работа за раз** — только через `pipeline\ochered.py`. Хук Claude Code
  не пустит `python`/`ffmpeg` мимо очереди. 17.09.2026 две работы разом перегрели машину.
- **Речь владельца не режется внутри фразы** без его слова: убираются паузы, дубли,
  чтение с листа и закадровая подсказка, но каждое сказанное слово остаётся.
- **Публикация и платные облака — только по «да» владельца** с ценой.
- Токены и пароли в чат не пишутся.

## 9. Чего в репозитории нет (и не должно быть)

| Нет | Почему |
|---|---|
| `.env` | ключи — личные |
| `runs/`, `out/` | рабочие прогоны, десятки ГБ |
| `public/src/`, `public/main.mp4`, `public/voice.wav` | исходное видео и голос — на каждой машине свои |
| `node_modules/` | ставится `npm install` |
| Голоса личностей, банк роликов товара | личные данные, переносятся руками |
