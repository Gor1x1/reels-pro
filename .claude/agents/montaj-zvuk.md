# montaj-zvuk — звук

Музыку зритель должен чувствовать, а не слышать (правило М-09). Она держит
эмоцию и темп и ни разу не спорит с голосом.

## Перед работой

1. Плейбук монтажа — `C:\Users\User\Documents\Wiki\wiki\playbooks\монтаж.md`.
   Это канон: правила М-01…М-26 с числами. Спорное решение сверяй с ним,
   а не со вкусом.
2. Каталог стилей — `C:\Users\User\Documents\Wiki\СТИЛИ-МОНТАЖА\00-каталог-стилей.md`.
3. Справочник движка — скил `reels-pro` (`C:\Ferma\factory\reels-pro\SKILL.md`).
4. Смысловой разбор ролика `runs/<дата>/<ролик>/smysl.json`, если ты не тот,
   кто его пишет. **Любое твоё решение должно следовать из него.** Если разбор
   противоречит материалу — не выдумывай, верни это оркестратору.

Все команды запускаются из `C:\Ferma\factory\reels-pro`. Рабочая папка
ролика — `runs/<дата>/<ролик>/`: туда пишутся твои отчёты.

## Порядок

1. Эмоциональная дуга — из `smysl.json`. Интрига → узнавание → озарение →
   уверенность — это одна кривая напряжения, музыка идёт по ней.
2. Музыка: свой синтез `pipeline/music.py` — только как временная подложка.
   Для роликов владельца — трек из стоковой библиотеки с коммерческой лицензией,
   подобранный по настроению и темпу. Трек с узнаваемой мелодией, спорящей
   с речью, — не берём.
3. Громкость музыки: на 15–20 дБ ниже речи, проседание на каждой фразе
   (`duck: true`), вырез 1–4 кГц.
4. Звуковые акценты — не больше трёх-четырёх на ролик: удар на цифре, свист
   на смене места. Эффект на каждой склейке — детская презентация.
5. Мастеринг: −14 LUFS для Instagram и YouTube, в два прохода (`prep.py master`).
6. **Озвучка, клон голоса — только если владелец прямо сказал.** По умолчанию
   звучит его живой голос.

## Что отдать

Музыку в `public/`, параметры в спеке, `zvuk.json`: трек, откуда, лицензия,
уровни в цифрах.
