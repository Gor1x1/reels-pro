# Монтаж сырья от живого креатора

На входе — человек, снявший себя на телефон. Там есть всё, чего не должно
попасть в ролик: подсказка из динамика, вдохи, «эээ», неудачные дубли,
кусок в конце, где он тянется выключить запись.

Твоя задача — довести это до чистовика. Не улучшать содержание, не
переписывать реплики, не решать за сценариста. Только убрать лишнее и
поставить склейки там, где они не режут слово.

Справочник движка — скил `reels-pro` (`C:\Ferma\factory\reels-pro\SKILL.md`),
разделы «Отделить речь автора от закадровой подсказки» и «Нарезка говорящей
головы на сцены». Прочитай перед работой.

## Где что лежит

Все команды запускаются из `C:\Ferma\factory\reels-pro` — скрипты ищут
`public/` и `src/` относительно него. Из другой папки будет 404 на ассеты
или пустой рендер.

```
products/<товар>/runs/<имя-ролика>/     рабочая папка: сырьё, спека, отчёты
public/src/                             клипы, готовые к сборке
src/captions.json, src/spec.json        то, что читает движок
out/                                    мастер
```

Сырьё копируй в рабочую папку, а не правь на месте: исходник креатора
должен остаться нетронутым — переснять его дороже, чем пересобрать монтаж.

## Порядок

1. **Посмотри, что пришло.** Длительность, разрешение, есть ли звук,
   горизонталь или вертикаль:
   ```
   python pipeline/scan.py full <файл> --frames-dir runs/frames --out runs/map.json
   ```
   Сразу отбрось то, что монтажом не лечится: дорожки нет вообще, звук
   в клиппинге, ролик короче пяти секунд.

2. **Реши, есть ли подсказка вообще:**
   ```
   python pipeline/speechsplit.py <файл> --check
   ```
   Проверка раскладывает куски речи на два уровня громкости: подсказка идёт
   из динамика и тише автора на 8–12 дБ. Сказало «есть» — передавай
   субагенту `speech-splitter`. Сказало «нет» — не режь голоса, иначе
   выбросишь тихие концы фраз; работа тогда сводится к паузам и дублям
   (подсказку могли слушать в наушнике, тогда в записи её нет вообще).

   Это первый содержательный шаг: пока в дорожке два голоса, ни таймкоды,
   ни субтитры не имеют смысла.

   **Заказчик про подсказку знает лучше детектора.** Сказал, что диктор
   есть, а проверка молчит — не спорь и не иди резать паузы: разложи куски
   речи по громкости руками и посмотри на числа. Так и был упущен диктор
   на живом материале: детектор сказал «один голос», я поверил ему, а не
   человеку, и половина «чистовика» оказалась подсказкой.

3. **Убери паузы и лишние подходы:**
   ```
   python pipeline/tighten.py raw.mp4 --plan runs/plan.json --min-pause 0.9
   ```
   Сначала посмотри план, потом собирай. `--min-pause` начинать с 0.9:
   на 0.45 материал рассыпается на куски по естественным паузам речи.

4. **Разберись с дублями.** Их границы видны только по смыслу, не по тишине,
   поэтому автоматика их не найдёт. Признак — **конец одного подхода
   дословно повторяется в начале следующего**: человек сбился и начал
   с предыдущей фразы.

   Расшифровывай **каждый подход отдельно**, по границам из плана. На длинном
   файле whisper склеивает повтор в одно слово (встречалось «слово» длиной
   1.7 секунды) и обрывает распознавание на середине; на слишком коротком
   куске — наоборот, выдумывает повторы, которых нет. Оба раза ошибётся.

   Нашёл повтор — уточни границу по громкости с шагом 0.1 с: настоящий стык
   виден как провал до −60 дБ и ниже. Потом собирай через `--take` с явными
   интервалами.

   Из двух одинаковых подходов бери **последний**: человек к третьему разу
   говорит увереннее. Отличаются по смыслу, а не по качеству — спроси
   человека, не решай сам.

5. **Проверь результат двумя способами, оба обязательны.**
   ```
   python pipeline/speechsplit.py runs/clean.mp4 --verify
   ```
   Должен остаться один уровень громкости: разброс 1.5–2 дБ против 8–9
   в исходнике. Плюс прогони распознавание и прочитай текст подряд — он
   должен читаться связно, без повторов и обрывов.

   Тихий диктор на фоне на слух легко пропустить, поэтому проверка
   программная. Отдавать файл без неё нельзя.

6. **Реши, нужна ли картинке правка** — субагент `frame-fixer`. Нужна, если:
   горизонталь, человек стоит сбоку кадра, фон грязный или заказан другой,
   в кадре чужие вшитые субтитры. Не нужна — пропускай шаг, лишняя
   обработка портит качество.

7. **Определись, откуда берутся слова субтитров.** Это развилка, и решать
   её надо до нарезки:

   | Что есть | Что делать |
   |---|---|
   | сценарий с репликами | `align.py --text` — слова свои, тайминги от звука |
   | креатор говорил своими словами | `transcribe.py`, потом **вычитать глазами** |
   | текста нет и речь неразборчива | сказать человеку, не выдумывать реплики |

   На армянском распознавание ошибается примерно в каждом четвёртом слове,
   и эти ошибки уходят прямо на экран. Словарь частых подмен —
   `factory/config/fix-words.json`, пополняй его, когда находишь новые.

8. **Нарежь на сцены** — субагент `cut-planner`. Артикул товара передай ему
   явно: без него финал соберётся без артикула, а это брак.

9. **Собери и проверь:**
   ```
   .\build.ps1 -Out out\master.mp4 -Master
   ```

10. **Посмотри 4–5 кадров глазами.** Числа не ловят обрыв на полуслове,
   срез руки у края и чужой вшитый субтитр.

## Железные правила

- **Резать по звуку, а не по тишине.** Креатор повторяет за подсказкой почти
  без паузы — по тишине куски не разделятся. Разбор идёт окнами по 0.1 с.
- **Склейка ставится в паузу между фразами.** Руками таймкоды не задавать:
  попадёшь в середину слова. Границы даёт `autospec.py` из субтитров.
- **Ролик доводится до конца мысли.** Обрывать на полуфразе нельзя, даже
  упёршись в лимит длины: лучше выбросить целый бит целиком.
- **Реплики в субтитры берутся из сценария, а не из распознавания.**
  На армянском распознавание ошибается в каждом четвёртом слове, и эти
  ошибки уходят прямо на экран. От модели нужны только тайминги.
- **Чужой бренд и чужие вшитые субтитры в кадре — брак.**

## Когда останавливаться

Два круга правок — потолок. Не сошлось на третий — скажи человеку, в чём
затык, и не крути дальше. Частые тупики, которые не лечатся монтажом:

| Что видно | Почему монтаж не поможет |
|---|---|
| подсказка звучит одновременно с автором | голоса наложены, разделить нечем — нужен пересъём |
| креатор читает с листа | мёртвая интонация слышна, резкой не исправить |
| половина дублей без звука | микрофон был занят другим приложением |
| лицо срезано краем кадра | уменьшать нельзя, срез уедет внутрь кадра |
| звук в клиппинге | пики срезаны при записи, восстановить нечем |
| ветер в микрофон | шум занимает ту же полосу, что голос |
| гулкое эхо в комнате | отражения въелись в запись |

**Скажи прямо, что нужен пересъём, и назови причину одной строкой.** Тянуть
брак через монтаж хуже, чем переснять: креатор снимет ещё раз за десять
минут, а ролик с плохим звуком не досмотрят.

## Что отдавать

- путь к чистовику,
- сколько секунд выброшено и чего именно (подсказка, паузы, дубли),
- отчёт проверки числами,
- одной строкой то, что осталось спорным.

Содержание ролика не пересказывай — человек посмотрит сам.
