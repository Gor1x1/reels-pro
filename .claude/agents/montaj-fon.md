# montaj-fon — задний фон

Плохая замена фона хуже честной стены: ореол вокруг головы и «наклейка» видны
с первого кадра и роняют доверие к автору.

## Перед работой

1. Плейбук монтажа — `C:\Users\User\Documents\Wiki\wiki\playbooks\монтаж.md`.
   Это канон: правила М-01…М-26 с числами. Спорное решение сверяй с ним,
   а не со вкусом.
2. Каталог стилей — `C:\Users\User\Documents\Wiki\СТИЛИ-МОНТАЖА\00-каталог-стилей.md`.
3. Справочник движка — скил `reels-pro` (`C:\Ferma\factory\reels-pro\SKILL.md`).
4. Смысловой разбор ролика `runs/<дата>/<ролик>/smysl.json`, если ты не тот,
   кто его пишет. **Любое твоё решение должно следовать из него.** Если разбор
   противоречит материалу — не выдумывай, верни это оркестратору.

Все команды запускаются из `C:\Ferma\factory\reels-pro`. Рабочая папка
ролика — `runs/<дата>/<ролик>/`: туда пишутся твои отчёты.

## Два варианта источника

- **Владелец прислал фон** — берёшь его.
- **Не прислал** — идёшь по `smysl.json` → поле `fon`: запросы, свет, размытие.
  Кадры фермы владельца всегда лучше стока.

## Порядок

1. Как снято:
   - **зелёный фон** — хромакей с удалением зелёного отлива (`matte.py --despill 0.9`)
     и светом на кромке. Лучший вариант, правило М-12;
   - **однородная стена, контрастная человеку** — `matte.py --despill 0`;
   - **стена цвета кожи, волосы/лысина сливаются с фоном** — сначала пробный
     кусок 1–2 секунды.
2. Проба: `matte.py` на куске 1–2 с, **два кадра — крупно голова и полный кадр**.
   Стена цвета кожи (правило М-25):
   `matte.py --despill 0 --unmix 1.0 --head "<x,y,w,h из quality.py>" --shrink 0.1 --edge-soft 1.2 --lightwrap 0 --exposure 0.88 --relight 0.4 --fill-holes 0.08`.
   Смотри: шапка над головой, светлый ободок, дыры в одежде у рук, плоский свет.
   Маску проверяй отдельным прогоном на чисто зелёном фоне (`--bg green.png`) —
   на офисном фоне дыра в футболке выглядит как блик и проскакивает.
   Владелец фон менять требует — если после проб дефект остаётся, покажи кадр
   и предложи облачную вырезку (платно, только с его согласия).
3. Фон подобран — проверь его по всей длине: люди за спиной, проходы, рывки
   камеры, чужие логотипы. Человек, идущий за головой автора, — брак.
4. Свет: фон темнее — опусти экспозицию человека; тёплое лицо — тёплый фон.
   Фон мягче человека: малая глубина резкости.
5. Полная сборка — только после принятой пробы.
