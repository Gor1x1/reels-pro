# Библиотека хуков (2025–2026)

## Цифры, которые нужно знать

- 50–60% зрителей уходят в первые 3 секунды
- Средний свайп происходит на ~5,8 секунде
- Сильные ролики держат intro retention 70%+, слабые умирают при <40%
- Хук за первые 2 секунды удерживает на 19% больше зрителей
- 90% эффекта запоминаемости рекламы — первые 6 секунд (TikTok For Business)
- Стратегия "hook за первые 3 секунды" даёт рост watch time в среднем на 58%

**Главный вопрос перед каждым роликом:** "Как зацепить за первые 2 секунды и удержать до 10?"

---

## Структура первых 3 секунд (обязательно)

```
0–0.5с  →  Визуальный pattern interrupt
0.5–2с  →  Hook-обещание (вопрос / боль / результат / bold claim)
2–3с    →  Уточнение ценности ("кому смотреть" и "что получишь если досмотришь")
```

Начинать с payoff, не с предыстории. "Вот результат → вот как" > "Сначала расскажу о себе".

## Топ-10 типов хуков

### 1. Curiosity / Open Loop
Создаёшь информационный разрыв.
- "This might get me cancelled, but…"
- "Nobody is talking about this."
- "I quit X for 60 days — вот что произошло."
Когда: обучающий контент, кейсы. Только если payoff реальный.

### 2. Shock / Bold Claim
Сильное утверждение с реальным бэкендом.
- "This 15-second video drove more traffic than our entire campaign."
Когда: paid ads, если дальше есть доказательства.

### 3. Pain / Negative Hook
- "Never overpay for [категория] again."
- "Stop [действие] if you're [аватар]."
Когда: e-commerce, ретаргетинг. Чем точнее боль — тем сильнее хук.

### 4. Before / After / Transformation
Визуальный контраст до → после. Split-screen, "Visible results in X days."
Когда: продукты с видимым результатом.

### 5. Social Proof / UGC
"Silent review" (продукт без слов, только мимика) — топ-формат 2024–2025 для TikTok.
Когда: DTC, SaaS, где важна доверка.

### 6. List / "X причин / ошибок"
- "3 mistakes killing your TikTok performance."
Когда: экспертный контент, paid ads.

### 7. POV / Relatable
- "POV: you spent 2 hours on a Reel and it got 132 views."
Когда: storytelling, личный бренд.

### 8. Pattern Interrupt
Неожиданное движение/звук — срабатывает до того, как человек осознанно решил смотреть.
Примеры: crash-zoom, отражение текста в очках, Post-it закрывающий продукт, размытый текст → фокус.
Когда: ВСЕГДА, как первый слой (0–0.5с).

### 9. Trend / Meme Hook
Тренд как шаблон повествования, адаптированный под бренд.
Когда: органика TikTok/Reels.

### 10. Silent / Facial Expression Hook
Только мимика + продукт, без слов.
Когда: товары "понятные глазами"; авто-mute аудитория.

## Слоистая структура хука

```
Слой 1: Визуальный pattern interrupt (обязательно)
Слой 2: Текст на экране с обещанием (крупно, 4–7 слов)
Слой 3: Voiceover / аудио, усиливающий смысл
```

Все три слоя работают одновременно — не заменяют, а усиливают.

---

## Формулы под ниши

**Продуктовая реклама:**
- "Never [неприятное действие] on [категория] again."
- "[Before] → [After] + '[результат за срок]'"
- "3 reasons this [product] replaced [старое решение]."

**AI-контент:**
- "I generated [результат] in [срок] using [инструмент]."
- "[Сырой кадр] → [AI-финал] + 'From this → to this in 30 seconds.'"

**Маркетинг / фриланс:**
- "[Результат] in [срок] using 1 [инструмент]."
- "[X] mistakes killing your [метрика]."
- "POV: [типичная ситуация]."

---

## Какие хуки убиты

Не использовать:
- "Stop scrolling!" — мертво
- "You won't believe this" — мертво
- "Want to grow on TikTok?" — мертво
- Любые абстрактные обещания без конкретики

Правило: вместо "Want to grow?" → "If you're posting Reels daily and stuck under 1K views…"

---

## Ad Fatigue

- После 4 одинаковых показов CTR падает ~45%
- При 6–10+ показах люди перестают реагировать

На одну идею — минимум 3–5 вариантов хука. Менять первые 3 секунды, middle можно оставить.

## Хуки по платформам

| Платформа | Приоритет | Особенности |
|-----------|-----------|-------------|
| TikTok | Аудио + визуал | Звук включен, нативность, тренды |
| Instagram Reels | Визуал + текст | 80% без звука, субтитры обязательны |
| YouTube Shorts | Текст + визуал | Result-first, ролики <15с → досмотр ~76% |
