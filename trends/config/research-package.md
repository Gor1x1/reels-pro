# Пакет исследования — что секция 1 отдаёт секции 2

Канон формата. По нему работают `trendy-lead`, `ref-analyst`, `pain-cluster`
и принимающий `scenarii-lead`. Меняется только по решению владельца.

Папка прогона: `runs\<ГГГГ-ММ-ДД>\<товар>\`

```
ПАКЕТ-<товар>.md            рабочий материал сценаристу
АНАЛИЗ-НЕДЕЛИ-<товар>.md    картина ниши владельцу
боли-<товар>.json           кластеры болей машинно
refs\top1.mp4 top1.txt      скачанные ролики, расшифровки, кадры
```

Скелеты форматов (`format-NN.json`) пишет `ref-analyst` в ту же папку,
когда разбор идёт по отдельному ролику вне общего пакета.

## 1. format-NN.json — скелет чужого формата

Отвечает на вопрос «что снимать»: как устроен залетевший ролик и как
перенести его на наш товар. Пишет `ref-analyst`, принимает `angle-builder`.

  "platform": "tiktok",
  "author": "@user",
  "published": "2026-08-10",

  "metrics": {
    "views": 1400000, "likes": 120900, "comments": 97, "shares": 3400,
    "outlier_multiplier": 4.9,
    "outlier_note": "в 4.9 раза выше обычного охвата этого автора"
  },

  "freshness": {
    "verdict": "на подъёме | на пике | на спаде",
    "evidence": "оригинал 5 дней назад, копии свежие, рекламы в выдаче нет"
  },

  "niche": "находки для дома",
  "format": "До / после",

  "hook": {
    "text": "дословно на языке оригинала",
    "translation": "перевод на русский",
    "visual": "что физически видно в первые 3 секунды",
    "type": "из справочника hooks.md",

      "speech": "что говорят", "screen_text": "текст на экране" }
  ],

  "retention": {
    "payoff_sec": 7.5,

`format` (из закрытого списка десяти), `hook.text` дословно, три блока,
`adaptation.idea` с конкретикой. Нет — `ref-analyst-check` возвращает работу.

## 2. pains.json — карта болей

Отвечает на вопрос «о чём говорить»: боль зрителя его же словами.
Пишет `pain-cluster`, принимают `angle-builder` и `hook-smith`.

```json
{
  "product": "гель Дюрин",
  "collected": "2026-08-15",
  "quotes_total": 214,
  "clusters": [
    {
      "id": "PAIN-03",
      "name": "Пятно возвращается после стирки",
      "description": "одно-два предложения по-русски",
      "awareness": "ищет решение",
      "scores": { "frequency": 9, "strength": 8, "commercial": 9,
                  "product_fit": 10, "filmability": 9 },
      "priority": 88,
      "quotes": [
        { "text": "стирала три раза, пятно как было так и есть",
          "translation": "—", "lang": "ru",
          "url": "https://...", "source": "wildberries",
          "date": "2026-07-20", "rating": 2 }
      ],
      "vocabulary": ["пятно не отходит", "как было так и есть"]
    }
  ]
}
```

**Обязательное:** 10–15 кластеров, у каждого 3–5 цитат с рабочими ссылками,
приоритет с составляющими оценками, словарь фраз дословно из банка.
Придуманных цитат быть не может — `pain-cluster-check` ловит их поиском
по банку.

## 3. research-report.md — отчёт человеку

Короткий текст на русском: какие три референса взяты и почему, их свежесть,
сколько цитат и кластеров собрано, что пропущено и почему, остаток денег
на Virlo, что требует решения владельца.

---

## Как это едет дальше

`angle-builder` берёт **боль из pains.json** + **формат из format-NN.json** +
свойство товара из `card.md` и собирает три варианта угла. Владелец выбирает
один (гейт 1) — дальше `tz-writer` пишет ТЗ, `hook-smith` кует хук из
дословной цитаты. То есть качество ТЗ упирается ровно в две вещи: живые
цитаты и честный разбор формата.
