# Запрещённые обороты — общий список для всех агентов

Штампы, по которым текст узнаётся как машинный или рекламный мусор.
Проверяется в любом тексте для людей: описания публикаций, ТЗ, реплики,
первый комментарий, отчёты. Список пополняется — нашёл новый штамп
в выдаче агента, добавь строкой сюда.

## Рекламные штампы (русский)

- «уникальный», «инновационный», «революционный», «эксклюзивный»
- «№1», «лучший на рынке», «нет аналогов»
- «настоящая находка», «незаменимый помощник», «маст-хэв»
- «идеально подойдёт для…», «побалуйте себя»
- «широкий ассортимент», «высокое качество по доступной цене»
- «успей купить», «только сегодня», «торопитесь» и любой искусственный дефицит
- КАПС В ПРЕДЛОЖЕНИЯХ и простыни эмодзи (⚡️🔥💥 подряд)

## Канцелярит и ИИ-обороты (русский)

- «данный» (→ «этот»), «является» (→ «—»), «осуществляет», «производит
  очистку» (→ «чистит»)
- «в современном мире», «в наше время», «не секрет, что», «как известно»
- «стоит отметить», «важно подчеркнуть», «следует заметить»
- «более того», «кроме того» в начале каждого второго абзаца
- «широкий спектр», «целый ряд», «богатый функционал»
- вопрос-открывашка «Хотите …? Тогда …» — мёртвый шаблон

## Армянский (тексты для зрителя)

- канцелярские кальки с русского; писать так, как говорят люди
  из словаря фраз банка болей, а не как пишет реклама
- не смешивать восточноармянский с западноармянскими формами
- слова про пятно: `հետք` или `լաքա`, **не** `բիծ` (правка владельца
  в карточке Дюрина — сверяться с card.md товара)

## Обещания

Любое обещание эффекта — только из карточки товара (`card.md`).
Чего нет в карточке — того нет в тексте, даже красивого.
Отдельный список запретов товара — `products/<товар>/claims.md`.
