# Термины аналитики по-армянски

Словарь рабочих слов секции трендов. Нужен, чтобы каждый прогон называл
хук, развитие и залёт **одинаково**: иначе банки разных недель перестают
быть сравнимыми, а сценарист каждый раз заново гадает, что имелось в виду.

Грамматика и живость слов — по
`config/skills/creator-tz-new-full/references/armenian_style.md`:
литературная «է», простые бытовые слова, короткие предложения.

> **Статус: черновик.** Утверждают носители — владелец и Мариам, как
> и в правилах стиля. Их правка слова заносится сюда и становится
> законом. До утверждения агент пишет по этой таблице, но помечает
> в отчёте, что словарь не подтверждён.

---

## 1. Что остаётся латиницей

По действующему правилу технические термины не переводятся и кальки
не выдумываются.

`Hook` · `CTA` · `Reels` · `Shorts` · `TikTok` · `Instagram` ·
номера банков `H-001` `R-001` `C-001` `T-001` `F-001` `X-001` ·
имена файлов и папок · `fps` · `9:16` · `1080×1920`

Хук в тексте пишется `Hook`, а не транслитом: так его узнаёт и креатор,
и монтажёр, и человек, читавший чужую документацию.

## 2. Основные понятия

| Русский | Армянский | Пояснение |
|---|---|---|
| улов | **որս** | всё, что монитор собрал за неделю |
| донор | **դոնոր** | чужой ролик, из которого взята деталь |
| сила залёта | **թռիչքի ուժ** | `ln(դիտումներ ÷ բաժանորդներ) × ln(բաժանորդներ)` |
| залетевший ролик | **թռած տեսանյութ** | |
| провал | **ձախողում** | ролик на ту же тему, который не взлетел |
| боль | **ցավ** | проблема аудитории её словами |
| кластер болей | **ցավերի կլաստեր** | |
| возражение | **առարկություն** | |
| угол | **անկյուն** | боль → свойство товара → обещание |
| ниша | **ոլորտ** | |
| формат | **ֆորմատ** | |
| контур поиска | **որոնման ուղի** | А категорийный, Б форматный, В звуковой |

## 3. Части ролика

| Русский | Армянский | Пояснение |
|---|---|---|
| хук | **Hook** | латиницей, см. пункт 1 |
| носитель хука | **Hook-ի կրիչ** | խոսք · էկրանի տեքստ · երկուսը · առանց խոսքի |
| развитие | **զարգացում** | что происходит после хука |
| концовка | **ավարտ** | последние секунды, призыв |
| приём | **հնարք** | как снято: ракурс, камера, монтаж |
| связка | **կապակցում** | Hook + զարգացում + ավարտ с замером |
| выплата хука | **Hook-ի կատարում** | секунда, где обещание исполняется |
| план (кадр) | **կադր** | единица монтажа |
| ритм планов | **կադրերի ռիթմ** | |
| титр | **տիտր** | текст на экране |
| раскадровка | **կադրապատում** | посекундная таблица для съёмки |

## 6. Статусы записей — не переводятся

Статусы читают агенты, поэтому остаются как есть: `новый` · `рабочий` ·
`слабый` · `отдых` · `архив`. Рядом в шапке банка даётся пояснение
по-армянски, чтобы человек понимал, что они значат:

```
նոր՝ չենք փորձարկել · рабочий՝ մեզ մոտ արդյունք տվել է ·
слабый՝ մեզ մոտ ձախողվել է · отдых՝ շատ ենք կրկնել ·
архив՝ դոնորը կես տարուց հին է
```

## 7. Чего не делать

- **Не выдумывать кальки** там, где слово уже прижилось: `ֆորմատ`,
  `կլաստեր`, `դոնոր` — нормальные заимствования, а `տեսաձև` вместо
  формата никто не поймёт.
- **Не переводить оригинал хука.** Перевод идёт строкой ниже, оригинал
  остаётся нетронутым.
- **Не смешивать языки внутри фразы**, кроме терминов из пункта 1.
- **Не переводить номера и имена файлов.**

## 8. Как пополняется словарь

Встретилось понятие, которого здесь нет, — агент выбирает слово по духу
таблицы, использует его **одинаково во всём документе** и выносит строкой
в отчёт: «новое слово: X = Y, прошу подтвердить». Владелец подтверждает —
слово попадает сюда.

Молча заводить термины нельзя: два прогона с разными словами для одного
понятия обесценивают банк.
