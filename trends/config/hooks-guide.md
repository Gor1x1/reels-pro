# Гид по крючкам: типы, механика, выбор

> Типология — от владельца (15.08.2026, список из его инструмента).
> Механика — разбор Claude по открытым источникам и логике формата.
> **Какой крючок работает у НАС — покажут только замеры**: тип каждого
> использованного хука пишется в `products\<товар>\hooks.json`, замеры
> 0–3 сек лягут туда же, и таблица выбора ниже будет переписана данными.
> До этого всё здесь — рабочая гипотеза.

## Типология: 15 крючков

| Тип | Механика (что дёргает) | Когда родной | Риски |
|---|---|---|---|
| **Боль / проблема** | узнавание себя: «это же про меня» | осознанная боль, есть дословные цитаты | без решения в ролике = чистый негатив |
| **Шок / нарушение правил** | паттерн-брейк: «так нельзя!» | демонстрации не по назначению, «гель с кухни — в душевую» | площадки режут шок-контент; товар обязан оправдать заявку |
| **Выгода / результат** | результат первым кадром | скептичная аудитория, «до/после» | показал всё сразу — досматривать незачем; нужна недосказанность «как» |
| **Конфликт / спорное мнение** | несогласие → комментарии → алгоритм | форматы-вердикты, «непопулярное мнение» | хейт; спор должен быть о проблеме, не о людях |
| **Ошибка / «делаете неправильно»** | лёгкая вина + любопытство | бытовые темы, уборка — вечный жанр | заезжен; спасает только конкретика ошибки |
| **Юмор / шутка** | расслабление, шеринг | персонажи с юмором (CP-07) | несмешно = провал; плохо масштабируется |
| **Необычный формат / визуал** | стоп-скролл глазами, без слов | генерация, макро, satisfying | быстро выгорает, мгновенно копируется |
| **Соцдоказательство (отзывы)** | «тысячи уже купили» | тёплая аудитория, ретаргет | каждое чужое слово сверять с claims.md |
| **«Все так делают»** | конформизм, FOMO нормы | привычки, ритуалы ухода | слабее для нового товара без известности |
| **Личный опыт / исповедь** | доверие через уязвимость | живые креаторы, длинные форматы | медленный старт — совмещать с интригой |
| **Секрет / интрига** | чистый разрыв любопытства | «никому не говорите», лайфхаки | пустой секрет = отписка и недоверие навсегда |
| **Эстетика / визуальный кайф** | satisfying, ASMR-эффект | **чистка и уборка — идеально**: пена, грязь сходит | слабый мост к CTA; смотрят и не покупают |
| **Срочность / дефицит** | страх упустить | продающие ролики, акции | на охватных роликах читается как фальшь |
| **Эмоции / мимика** | заражение эмоцией с лица | лицо крупно в кадре | у фермы лиц нет → эмоция только голосом и монтажом |
| **ИИ** | новизна технологии | техно-ниши | приедается; к нашим товарам не мост |

## Про «шок, страх, гнев» — как использовать сильные эмоции

Негативные эмоции цепляют сильнее позитивных — это подтверждено. Но три
правила безопасности:

1. **Страх обязан разрешаться товаром в этом же ролике** — напугал
   и не спас = зритель уходит с негативом к бренду.
2. **Гнев направляем на проблему или «индустрию»** («нас годами заставляли
   покупать пять средств»), никогда — на зрителя и никогда — на конкурента
   по имени (claims.md, п.4).
3. **Шок — в заявке, не в картинке**: жесть в кадре режут алгоритмы
   и жалобы. «Гель для плиты — в душевую» — шок нарушения правил без
   единого рискованного кадра.

## Как выбирать крючок под сценарий (правило для hook-smith)

1. Смотри **стадию осознанности боли** в pains.json: боль осознана →
   Боль/Ошибка/Секрет; не осознана → Шок/Конфликт/Визуал.
2. Смотри **формат**: Тест на себе → Шок, Конфликт-сомнение, Ошибка ·
   До/после → Выгода, Эстетика · Польза-гайд → Секрет, Ошибка ·
   Обзор → Соцдоказательство, Личный опыт.
3. Смотри **персонажа**: крючок не должен ломать характер (CP-04 не может
   в Эстетику, CP-03 не может в Шок).
4. **Восьмёрка hook-smith покрывает минимум 4 разных типа** — иначе A/B
   меряет формулировки, а не механики.
5. Тип каждого хука пишется в `hooks.json` полем `тип` — по замерам
   копилка плейбука `сценарии-и-хуки` превратит эту таблицу из гипотезы
   в знание.

## Что опровергнет

Замеры 0–3 сек по 30+ публикациям на тип: если тип из «родных» стабильно
проигрывает «неродному» — таблица выбора переписывается данными, а не
логикой.
