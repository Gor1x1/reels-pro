# Язык документа: армянский, литературная грамматика, простые слова

Читай этот файл до того, как начнёшь писать текст документа.

## Правило в одну строку

Весь документ на восточноармянском. Грамматика — литературная. Слова — те,
которыми люди говорят каждый день. Документ должен читаться как понятная
инструкция, а не как официальная бумага.

## 1. Грамматика — литературная

Копула «է», не разговорная «ա». Это касается всего документа одинаково:
и реплик героя, и режиссёрских указаний, и описаний.

| Не писать | Писать |
|---|---|
| սկսում ա | սկսում է |
| նայում ա | նայում է |
| դնում ա | դնում է |
| պիտի | պետք է |
| ուզում ա ասի | ուզում է ասել |

## 2. Слова — простые

Книжные и канцелярские слова заменяй бытовыми. Смысл тот же, читается легче.

| Не писать | Писать |
|---|---|
| իրականացնել | անել |
| իրականացվում է | արվում է |
| կատարել (в значении «сделать») | անել |
| տեղակայել | դնել |
| դիտարկել | նայել |
| ցուցաբերել | ցույց տալ |
| ապահովել | անել / տալ |
| ձեռք բերել | վերցնել / գնել |
| անհրաժեշտ է | պետք է |
| հանդիսանում է | է |
| իրենից ներկայացնում է | է |
| առկա է | կա |
| գտնվում է | է |
| նպատակով | համար |
| հետևաբար | դրա համար |
| այնուհետև | հետո |
| սակայն | բայց |
| ինչպես նաև | նաև |
| բավականաչափ | բավական |
| մեծ քանակությամբ | շատ |
| նվազագույնը / առավելագույնը | ամենաքիչը / ամենաշատը |
| լաթ | շոր (тряпка) / անձեռոցիկ (салфетка) — правка владельца 15.08.2026 |

Список не закрытый. Принцип: если слово не прозвучало бы в обычном разговоре
на кухне — ищи замену. Финальные арбитры живости языка — владелец и Мариам:
их правка слова заносится в эту таблицу и становится законом.

## 3. Предложения — короткие

Одно указание — одно предложение. Не склеивай через «որը», «ինչի
արդյունքում», «այն դեպքում երբ».

Плохо: «Ձեռքը, որը գտնվում է կադրի աջ մասում, վերցնում է ապրանքը այն
նպատակով, որ ցուցաբերի պիտակը:»

Хорошо: «Աջ ձեռքը վերցնում է ապրանքը: Պիտակը շրջում է դեպի օբյեկտիվ:»

## 4. Технические термины не переводить

Всё, что креатор и монтажёр видят в интерфейсе или произносят как есть,
остаётся латиницей или привычным заимствованием. Не выдумывай армянские
кальки.

Оставлять как есть: CapCut, keyframe, Scale, Speed, Glow, Bokeh, Blur,
Vignette, zoom in, zoom out, slow-motion, cut, fade in, fade out, ambient,
SFX, BPM, fps, MP4, H.264, 9:16, 1080×1920, px, dB, kHz, denoise, EQ,
штатив, петличка, Hook, CTA.

Названия брендов и продуктов — в оригинальном написании,
не транслитерировать.

## 5. Числа и единицы

0–4 վրկ · 1.2 մ · 45° · ×1.5 · 50% · 0.5 վրկ · #FF4444 · 72px

Секунда — վրկ, метр — մ, сантиметр — սմ. Диапазон через тире без пробелов:
4–13.

## 6. Кавычки

Реплики и титры — в ёлочках: «...». Внутри режиссёрских указаний название
эффекта или кнопки — без кавычек, просто латиницей.

## 7. Чего в документе нет никогда

- Колонки или строки с переводом на другой язык — ни при каких условиях,
  даже если референс был русским или английским.
- Смешения языков внутри одной фразы: реплика героя целиком на армянском,
  без вставленных русских слов (кроме терминов из пункта 4, если они звучат
  в кадре).
- Отдельного раздела «что нельзя делать креатору».

## 8. Проверка перед сдачей

Перечитай готовый текст и найди: (1) любую «ա» вместо «է», (2) любое слово
из левой колонки таблицы пункта 2, (3) предложение длиннее двух строк.
Всё найденное — переписать.
