# Удержание, Payoff и Share-триггеры

## Как удерживать зрителя после хука

### Pattern Interrupt внутри ролика
Планировать 2–3 interrupt'а на каждые 30 секунд:

- **Визуальный**: смена ракурса, zoom, смена формата (говорящая голова → close-up продукта → текст-карточка)
- **Аудио**: дроп музыки, тишина 0.2–0.4с перед ключевой фразой
- **Логический**: "Большинство делают X. Поэтому это не работает."
- **Форматный**: монолог → POV → insert → wide

Принцип: зритель не должен предсказать следующие 2–3 секунды. Контролируемая вариативность — не хаос.

### Темп
- Менять что-то каждые ~3 секунды (план, информация, движение)
- Ускорять: конфликт, действия, демонстрация
- Замедлять: ключевая мысль, главный reveal, финальная эмоция
- Убирать всё до первого смыслового слова в реплике
- Резать кадр сразу после того, как действие стало понятно

### Открытые петли
Незакрытый вопрос или недосказанное действие удерживает мозг до развязки:
- Обрыв на полуслове
- "Но сначала — важный момент..."
- Before-кадр без After
- Замороженный момент перед действием

## Финал и Payoff

### Главное правило
Финал должен **исполнить обещание хука**. Зритель должен почувствовать: "я досмотрел не зря."

"Если бы зритель посмотрел только первые 10 секунд — сказал бы он, что его обманули?"

### Эмоция важнее логики
Люди делятся не фактами — а тем, что им дали почувствовать. Финал должен давать эмоцию, а не вывод.

Рабочие финальные эмоции:
- Облегчение (боль решена)
- Удивление (неожиданный twist)
- Теплота (трогательный момент)
- Катарсис (напряжение отпустило)
- Вдохновение (это возможно!)
- Юмор (неожиданная концовка)

## CTA под тип контента

### Платная реклама (performance)
Один CTA, не несколько. Комбо: голос + текст + визуал продукта.

Шаблоны:
- "Download [Brand] today and [конкретный результат]."
- "Start for free today" + сайт / QR
- "Today only / Spots are limited" (если есть реальная причина)

Финальный кадр: продукт крупно, CTA-кнопка видна, логотип в углу.

### Органика (TikTok/Reels)
Цель — вовлечение и шаринг, не клик.

Шаблоны:
- "Отправь другу, у которого [та же боль]."
- "Сохрани — step 3 важнее всего."
- "Напиши [слово] — пришлю полный гайд."
- "Если это помогло — перешли тому, кто застрял."

### Брендовое кино
Мягкий финал без давления. Инсайт-фраза, которую хочется процитировать.

Пример:
```
"I thought AI would replace me.
Instead, it became the assistant that let me choose my clients."

Под ним маленький текст: "Want my exact prompts? Save this."
```

## Психология шаринга: почему делятся

5 триггеров, которые заставляют нажать "переслать":

**1. Identity** — ролик позволяет сказать "это про меня / это я"
Пример: конкретная ситуация, которая точно описывает аудиторию.

**2. Social Connection** — повод переслать другу ("это твоё")
Финальная фраза: "Send this to the friend who always [ситуация]..."

**3. Value / Полезность** — конкретный фреймворк или чек-лист, который хочется сохранить
Финальный экран с мини-шпаргалкой (3 шага, 4 ошибки).

**4. Эмоция** — awe / joy / relief / catharsis
История где герой выходит из кризиса, музыка на пике в финале.

**5. Новизна** — инсайд или тренд, о котором "мало кто знает"
"Если знаешь — поделись, пусть знают все."

## Инсайт-фраза (цитируемый финал)

Лучшие финалы содержат одну фразу, которую хочется скопировать и отправить.

Формула инсайт-фразы:
```
[Общепринятое убеждение] → [Неожиданный поворот]
```

Примеры:
- "AI doesn't replace you. It replaces your excuses."
- "I thought more clients was the goal. Turns out, fewer is freedom."
- "The world went quiet. Finally."

Одна фраза. Не абзац. Она должна умещаться в один скрин.

## Визуальный язык 2025–2026 (что выглядит современно)

**Работает:**
- Вертикаль 9:16, изначально спланированный под мобилку
- Bold minimalism: много воздуха, 1–2 объекта, крупный жирный текст + акцентный цвет
- Кинетическая типографика: текст "играет" — scale, bounce, slide под ритм
- Dark mode + неоновые акценты для техно/AI тематики
- Натуральный skin-tone и мягкий грейдинг для органики
- "Aura effect": яркий насыщенный градиент вокруг объекта / текста
- Cherry red / deep burgundy как акцентный цвет 2025
- Смена крупности каждые 1–2 секунды

**Устарело (не использовать):**
- Горизонтальные видео с чёрными полосами
- "Переглянцованный" TV-style ролик без нативности
- Плавные длинные dissolve-переходы
- Мелкий статичный текст без анимации
- Оранжево-teal LUT, убивающий детали
- Стоковый видеоряд + корпоративный голос

**Правило текста:**
- Крупные sans-serif шрифты, высокий контраст
- Максимум 4–7 слов за один появившийся блок
- 2–3 секунды на чтение одного блока
- Ключевые слова — отдельным ударом (scale / bounce)

## Чек-лист финала перед релизом

☐ Финал исполняет обещание хука?
☐ Есть одна финальная эмоция (не несколько одновременно)?
☐ Есть инсайт-фраза, которую хочется процитировать?
☐ CTA один и конкретный?
☐ Последний кадр содержит: визуал продукта / логотип / CTA-текст?
☐ Ролик работает без звука (только визуал + текст)?
☐ Ролик понятен без первых 3 секунд? (если нет — хук рабочий)
