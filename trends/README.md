# Trends — секция анализа трендов

Набор агентов для Claude Code, который отвечает на два вопроса по любому
товару: **что сейчас работает в этой нише** и **что болит у аудитории её
собственными словами**.

На выходе — пакет, из которого сценарист пишет технические задания,
и накопительные банки деталей: хуки, развития, концовки, приёмы, провалы.

Вторая секция этого репозитория — [монтаж](../README.md), он собирает
готовый ролик. Секции независимы: анализ можно ставить без монтажа
и наоборот.

---

## Зачем это

Модель работы: **много роликов по проверенным чужим схемам → замеряем →
размножаем залетевший формат.** Чтобы так работать, нужен постоянный
поток проверенных схем — их поставляет эта секция.

Чужой залетевший ролик разбирается не на «идею», а на детали, и каждая
деталь получает номер. Из двадцати хуков, двадцати развитий и десяти
концовок выходит четыре тысячи комбинаций: берём хук одного донора,
развитие второго, концовку третьего — это не копия, а новая сборка
из проверенных частей.

## Установка

**1. Скопировать агентов** в папку агентов Claude Code:

```powershell
Copy-Item trends\agents\*.md "$env:USERPROFILE\.claude\agents\"
```

**2. Подключить Virlo** — сервис разведки коротких видео. Зарегистрироваться
на virlo.ai, взять API-ключ в разделе API и прописать в
`%USERPROFILE%\.claude.json`, раздел `mcpServers`:

```json
"virlo": {
  "type": "http",
  "url": "https://dev.virlo.ai/api/mcp/mcp",
  "headers": { "Authorization": "Bearer ВАШ_КЛЮЧ" }
}
```

**3. Поставить программы:**

```powershell
python -m pip install -U --pre "yt-dlp[default]"
python -m pip install faster-whisper
```

Плюс ffmpeg в PATH. `--pre` обязателен: стабильная сборка yt-dlp отстаёт
и ломается на TikTok.

**4. Указать корень рабочей папки**, если он не `C:\Ferma\factory`:

```powershell
setx FACTORY_DIR "D:\ваш\путь\factory"
```

**5. Разложить конфиги и завести товар:**

```
<корень>\config\          ← из trends\config\
<корень>\lib\             ← из trends\lib\
<корень>\products\<товар>\ ← из trends\templates\
<корень>\runs\            ← создастся сам
```

Проверка, что всё живо: скажите Claude «проверь баланс Virlo» — вызов
бесплатный.

## Как пользоваться

Одна фраза:

```
проанализируй <товар>
```

Дальше агент идёт до готового результата сам. Полтора-два часа на прогон,
день на заведение нового товара с нуля.

### Что получится

**Разовое — отчёт об этом прогоне,** папка `runs\<дата>\<товар>\`:

| Файл | Кому |
|---|---|
| `ПАКЕТ-<товар>.md` | сценаристу — главный рабочий документ |
| `АНАЛИЗ-НЕДЕЛИ-<товар>.md` | владельцу — картина ниши на пять минут |
| `боли-<товар>.json` | агентам — кластеры болей машинно |
| `refs\` | скачанные ролики, кадры, расшифровки речи |

**Накопительное — имущество товара,** папка `products\<товар>\banks\`:
`hooks.md` · `development.md` · `endings.md` · `techniques.md` ·
`fails.md` · `combos.md`.

> Пакет — газета за сегодня: прочитали и выбросили.
> Банки — библиотека: растут с каждым прогоном и работают годами.

**Начинать читать с [РУКОВОДСТВО.md](РУКОВОДСТВО.md)** — оно написано для

чек-лист приёмки.

## Агенты

Вход один: `trendy-lead`. Остальных он зовёт сам.

| Агент | Что делает |
|---|---|
| `trendy-lead` | ведёт цикл: улов, отбор, разбор, банки, углы, пакет |
| `ref-downloader` | качает чужой ролик на диск через yt-dlp |
| `ref-analyst` + `-check` | разбор ролика на скелет формата и проверка |
| `pain-hunter` | охотник за болями, ведёт четырёх добытчиков |
| `pain-forum` `pain-social` `pain-marketplace` `pain-comments` | четыре источника цитат, работают параллельно |
| `pain-cluster` + `-check` | схлопывает цитаты в кластеры с приоритетами |
| `bank-keeper` | раскладывает находки по банкам, ведёт нумерацию |
| `combo-keeper` | пишет связки — только по подтверждённым замерам |
| `hook-scorer` | ставит хукам статусы по реальным результатам |
| `trend-critic` | судит, хватит ли материала на неделю ТЗ |
| `stock-reels` | разбирает банк готовых роликов товара |
| `product-keeper` `product-claims` `product-research` | заводят карточку товара и запреты |

### Развязки — сделаны намеренно

- **Ветка трендов и ветка болей не общаются** — идут параллельно
  по разным источникам и сходятся только у оркестратора.
- **Четыре добытчика не видят находок друг друга** — иначе сойдутся
  на одной популярной формулировке.
- **Проверяющие не переделывают работу** — возвращают номер
  невыполненного пункта. Максимум два круга, дальше человек.
- **Хранитель банка не ставит статусы по замерам** — это другой агент.
- **Секция не пишет сценарии.** Мы даём идею — что показать; как снять,
  решает сценарист.

## Правила, на которых всё держится

**Ранжирование по силе залёта, а не по просмотрам:**

```
сила = ln(просмотры ÷ подписчики) × ln(подписчики)
```

Ролик на миллион у миллионника сработал именем — копировать нечего.
Ролик на 50 тысяч у автора с 5 тысячами подписчиков сработал форматом.

**Площадки не сравниваются между собой.** Обычный ролик: TikTok ~39 000,
Reels ~3 800, Shorts ~1 000.

**Хук хранится дословно, как у донора** — без смягчения. Банк хранит факт
о том, что сработало; подмена формулировки на входе означает, что мы
никогда не узнаем, что именно дало результат.

**У каждого хука указан носитель** — речь, текст на экране, оба или без
слов. Иначе сценарист поставит закадровый голос там, где у донора
стоял титр.

**Пять сильнейших роликов разбираются глазами**, а не по машинной
разметке. На разборе ниши сухофруктов так выяснилось, что два из трёх
сильнейших роликов почти без речи, а один — вообще без единого слова
при 1,5 млн просмотров.

**Один анализ — один товар.** Сравнения с другими товарами в пакет
не попадают.
