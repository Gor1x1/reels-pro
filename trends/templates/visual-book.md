# Визуальная книга · <товар>

> **Кто заполняет.** Агент заводит пустой каркас. **Наполняете вы** —
> что реально снять вашими руками, знает только человек.
>
> **Что нужно от вас.** Перечислить сцены, которые вы способны снять:
> есть реквизит, есть место, товар в кадре ведёт себя как надо.
>
> **Если оставить пустым.** Агент будет строить идеи вслепую и предложит
> сцены, которые вы не сможете снять. Половина работы уйдёт впустую.

**Статусы:** `гипотеза` не проверяли · `рабочая` снимали, получилось ·
`не выходит` пробовали, в кадре плохо.

---

## Что можем снять

> По строке на сцену. «Что видно» — то, что окажется в кадре,
> а не название приёма.

| Сцена | Что видно | Чем снимается | Статус |
|---|---|---|---|
| <например: макро-план текстуры> | <крупно продукт, видно структуру> | <телефон, свет из окна> | гипотеза |
| | | | |
| | | | |

## Чего снять нельзя

> **Тоже важно.** Честный список экономит время: агент не будет
> предлагать невозможное.

<нет реквизита · нет локации · товар так себя не ведёт · некому сниматься>

## Что есть под рукой

> Реквизит, фактуры, места. Из этого списка агент собирает предложения.

<посуда, ткани, поверхности, техника, где снимаем>
