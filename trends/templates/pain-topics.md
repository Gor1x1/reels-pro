# Темы для поиска болей · &lt;товар&gt;

Самый важный файл владельца. По нему охотник ищет живые разговоры людей.

**Пишутся темы-проблемы, а не названия товаров.**

| Плохо | Хорошо | Почему |
|---|---|---|
| гель для стирки | не отстирывается детская одежда | по первому найдутся магазины, по второму — живые люди |
| чистящее средство | нагар на плите не отходит | |
| бытовая химия | сода дешевле, зачем покупать | это возражение, из него выйдет сильный хук |

**Язык поиска — русский.** Боли у людей одинаковые независимо от языка;
русские источники индексируются, армянские сидят в закрытых группах.
Звучание армянской реплики даёт `persona-adapter` на этапе сценария.

**Самый ценный блок — возражения.** Спорное цепляет сильнее нейтрального,
и лучшие хуки выходят именно оттуда.
