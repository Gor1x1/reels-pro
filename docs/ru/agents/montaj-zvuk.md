# montaj-zvuk — звук

Музыку зритель должен чувствовать, а не слышать (правило М-09). Она держит
эмоцию и темп и ни разу не спорит с голосом.

## Порядок

1. Эмоциональная дуга — из `smysl.json`. Интрига → узнавание → озарение →
   уверенность — это одна кривая напряжения, музыка идёт по ней.
2. Музыка: свой синтез `pipeline/music.py` — только как временная подложка.
   Для роликов владельца — трек из стоковой библиотеки с коммерческой лицензией,
   подобранный по настроению и темпу. Трек с узнаваемой мелодией, спорящей
   с речью, — не берём.
3. Громкость музыки: на 15–20 дБ ниже речи, проседание на каждой фразе
   (`duck: true`), вырез 1–4 кГц.
4. Звуковые акценты — не больше трёх-четырёх на ролик: удар на цифре, свист
   на смене места. Эффект на каждой склейке — детская презентация. Место —
   хук, смена темы, развязка и акценты из `zamysel.json`, не случайные стыки.
4а. **Звук — второй клей стыка (М-33).** Без звука зрители замечают почти все
   склейки. На каждом стыке из `edl.json` голос и музыка не проваливаются:
   огибающая не падает ниже −40 dBFS дольше кадра, проседание музыки не
   раскрывается в паузу между кусками встык. Громкость музыки — средняя: у
   звукового возбуждения есть оптимум, громче — хуже.
   Тишина перед главным словом (М-42) принята владельцем с условием: **паузу не
   слышно**. Музыка в ней не обрывается и не поднимается — держится на уровне
   проседания под речью; ни удара, ни эффекта в паузу. Проседание в движке
   держится, пока между титрами меньше 0.6 с: у паузы должны быть титры с обеих
   сторон, иначе музыка в ней поднимется.
5. Мастеринг: −14 LUFS для Instagram и YouTube, в два прохода (`prep.py master`).
6. **Озвучка, клон голоса — только если владелец прямо сказал.** По умолчанию
   звучит его живой голос.

## Что отдать

Музыку в `public/`, параметры в спеке, `zvuk.json`: трек, откуда, лицензия,
уровни в цифрах.

## Очередь — закон (М-44)

Приказ владельца 17.09.2026: прогон, где одновременно шли ffmpeg по 4K и
распознавание речи, перегрел компьютер до мерцания экрана. Пока идёт монтаж —
одна тяжёлая работа за раз. С 17.09 закон держит механизм, а не память агента.
- **Тяжёлое — только через очередь.** ffmpeg с `-i`, распознавание, вырезка
  фона, рендер, замеры, python-код с ffmpeg, whisper, torch, onnxruntime, cv2:
  `python pipeline/ochered.py -- <команда>`. Очередь ждёт конца предыдущей
  работы, даёт 18 из 24 потоков (датчик температуры молчит — 12) и приоритет
  ниже обычного,
  при перегреве ставит работу на паузу, после обрыва снимает хвосты.
  Скрипты `pipeline/*.py` и `build.ps1` встают в очередь сами — их зовут как
  обычно.
- **Хук не пустит мимо.** Команду мимо очереди Claude отклоняет и отвечает
  готовой командой через очередь — её и запускай. Не переписывать команду,
  чтобы хук её не узнал, и не выставлять `REELS_OCHERED` руками: это обход
  закона.
- **Занято — код 75.** Очередь занята дольше 9 минут: не обходить, повторить ту
  же команду позже. Что идёт — `python pipeline/ochered.py status`; снять свою
  зависшую работу — `python pipeline/ochered.py stop`.
- **Долгое.** Работа дольше 10 минут — в фоне инструмента
  (`run_in_background`), и пока она идёт, тяжёлого не запускать. Стоять при
  этом не нужно: шаги, которым её результат не нужен, идут рядом лёгкими.
- **Лёгкое рядом с тяжёлой** (решение владельца 17.09.2026, чтобы монтаж не
  стоял час на одной работе). Короткая нетяжёлая команда — ffprobe, кадры для
  листа, замеры звука, `qc.py`, стоки — пускается вторым местом:
  `python pipeline/ochered.py --lyogkaya -- <команда>`. Решает очередь, а не

  раньше тяжёлой — от 80 °C, и если процессор не остыл за 10 минут, снимается
