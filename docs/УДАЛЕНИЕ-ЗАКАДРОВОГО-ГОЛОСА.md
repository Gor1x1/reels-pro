# Как вырезать закадрового диктора и оставить только голос автора

Передача метода агенту-монтажёру. Задача: в сыром видео автор повторяет за подсказкой
(суфлёром/диктором). Нужно оставить **только речь автора**, подсказку убрать полностью.

Разобрано на реальном материале: `IMG_7406.MOV`, 81.5 с → 29.9 с чистой речи.

---

## 1. Почему «просто обрезать» не работает

Если у тебя после монтажа **голос диктора остаётся на фоне** — причина в одной из четырёх.
Проверь по списку, скорее всего дело в первой.

### Ошибка 1. Резать по тишине вместо разделения голосов

`silencedetect` находит паузы, но **не знает, кто говорит**. Он одинаково видит и подсказку,
и автора — обе реплики для него просто «звук». Убирая тишину, ты склеиваешь подсказку с автором.

> **Правильно:** сначала диаризация (кто говорит), и только потом нарезка.

### Ошибка 2. Верить границам слов из ASR

Транскрайберы часто включают в последнее слово хвост тишины и **начало следующей реплики**.
В нашем материале Scribe отдал сегмент автора как `7.20–13.60`, хотя реально он замолкает
на `11.09` — оставшиеся 2.5 с это пауза, за которой уже начинается подсказка. Возьмёшь `13.60` —
получишь диктора в кадре.

> **Правильно:** уточнять правый край через `silencedetect`.

### Ошибка 3. Порог тишины взят наугад

Подсказка звучит из динамика и тише автора. Если поставить порог `-50dB`, детектор посчитает
подсказку «звуком» и не даст обрезать. Если `-20dB` — срежет тихие окончания слов автора.

> **Правильно:** порог ставить **между** уровнями: выше подсказки, ниже автора.
> У нас подсказка −39…−35 dB, автор −27…−26 dB → порог `-34dB`.

### Ошибка 4. Не выброшены фальстарты

Автор часто начинает фразу, сбивается и повторяет её целиком. Обе версии — его голос,
диаризация их не различит. Останутся обе — монтаж выглядит рвано.

> **Правильно:** глазами сравнить соседние сегменты одного говорящего: если текст повторяется,
> оставить более полный.

## 2. Метод целиком

```
исходник
  ↓ 1. диаризация            кто говорит и когда
  ↓ 2. три проверки          какой из голосов — автор
  ↓ 3. EDL                   только сегменты автора, без фальстартов
  ↓ 4. точные границы        правый край по silencedetect
  ↓ 5. нарезка + склейка     микро-фейды на стыках
  ↓ 6. контроль              в финале должен быть ОДИН голос
```

---

## 3. Шаг 1 — диаризация

Определяет, сколько голосов в дорожке и какой где. Используем ElevenLabs Scribe.

```bash
KEY=$(sed -n 's/^ELEVENLABS_API_KEY=//p' ~/Developer/video-use/.env)

ffmpeg -v error -i input.MOV -vn -ar 44100 -ac 1 -b:a 192k src.mp3 -y

curl -s -H "xi-api-key: $KEY" \
  -F "model_id=scribe_v1" \
  -F "diarize=true" \
  -F "language_code=hye" \
  -F "file=@src.mp3" \
  https://api.elevenlabs.io/v1/speech-to-text -o scribe.json
```

`diarize=true` — ключевой параметр, без него разделения голосов не будет.
`language_code` — по языку исходника (`hye` армянский, `rus` русский, `eng` английский).

Сборка слов в сегменты (новый сегмент при смене говорящего или паузе > 1.2 с):

```python
import json
d = json.load(open("scribe.json"))
ws = [w for w in d["words"] if w.get("type") == "word"]

segs, cur = [], None
for w in ws:
    s = w.get("speaker_id")
    if cur is None or cur["spk"] != s or w["start"] - cur["end"] > 1.2:
        cur = {"spk": s, "start": w["start"], "end": w["end"], "text": w["text"]}
        segs.append(cur)
    else:
        cur["end"] = w["end"]
        cur["text"] += " " + w["text"]
```

**Что увидишь при схеме «подсказка → повтор»:** идеальное чередование.

```
 0 [  0.40-  1.34] speaker_0  Ողջույն այն անձանց,
 1 [  1.70-  2.64] speaker_1  Ողջույն այն անձանց,     ← тот же текст
 2 [  3.06-  6.82] speaker_0  ովքեր թեկուզ մի քիչ...
 3 [  7.20- 13.60] speaker_1  ովքեր թեկուզ մի քիչ...  ← тот же текст
```

## 4. Шаг 2 — какой голос принадлежит автору

Диаризация даёт `speaker_0` / `speaker_1`, но **не говорит, кто из них автор**. Номера
произвольные и в другом файле могут поменяться местами. Проверяем тремя способами —
они независимы, и совпадение всех трёх даёт уверенность.

### Проверка А. Порядок реплик

Автор **повторяет за** подсказкой, значит его сегмент всегда второй в паре.

```python
first = min(s["start"] for s in segs if s["spk"] == "speaker_0")   # 0.40
first = min(s["start"] for s in segs if s["spk"] == "speaker_1")   # 1.70  ← автор
```

### Проверка Б. Громкость

Подсказка идёт из динамика/наушника — она тише. Автор говорит в микрофон.
Замеряем RMS на двух-трёх сегментах каждого:

```bash
ffmpeg -hide_banner -ss 4.0 -to 6.5 -i input.MOV -af astats -f null - 2>&1 | grep -m1 "RMS level dB"
```

Реальные значения из нашего материала:

| Сегмент | RMS |
|---|---|
| speaker_0 [4.0–6.5] | **−39.4 dB** |
| speaker_1 [8.0–12.0] | **−27.2 dB** |
| speaker_0 [47.0–50.5] | **−35.1 dB** |
| speaker_1 [52.0–56.0] | **−26.6 dB** |

Разница 9–12 dB. Кто громче — тот автор.

### Проверка В. Губы на кадре (решающая)

Вырезаем кадр в момент реплики каждого говорящего и смотрим рот:

```bash
# момент, где по диаризации говорит speaker_0
ffmpeg -v error -ss 5.0 -i input.MOV -frames:v 1 \
  -vf "crop=380:230:170:400,scale=280:-1" lips_s0.jpg -y
# момент speaker_1
ffmpeg -v error -ss 10.0 -i input.MOV -frames:v 1 \
  -vf "crop=380:230:170:400,scale=280:-1" lips_s1.jpg -y
```

У подсказки рот **закрыт** (человек слушает), у автора **открыт**. Это самая надёжная
проверка: она не зависит ни от громкости, ни от порядка.

> Кроп подбирается под кадр: `crop=ширина:высота:x:y`. Для вертикали 720×1280 с лицом
> по центру область рта примерно `380:230:170:400`.

## 5. Шаг 3 — EDL только из сегментов автора

```python
DROP = {9, 33}   # индексы сегментов на выброс, см. ниже
edl = [s for i, s in enumerate(segs) if s["spk"] == "speaker_1" and i not in DROP]
```

**Что попадает в DROP:**

1. **Фальстарты.** Сегмент 9: `ստեղծում է այս պահի դրությամբ,` — фраза оборвана.
   Сегмент 11: `ստեղծում է այս պահի դրությամբ բաժիններ,` — та же фраза целиком.
   Оставляем 11, выбрасываем 9.
2. **Техническая болтовня.** Сегмент 33: `Լավ` («ладно») — реакция после съёмки, не текст.

Как находить: пройтись по сегментам автора и сравнить соседние — если начало текста
повторяется, это фальстарт.

## 6. Шаг 4 — точные границы

Правый край из ASR доверять нельзя (см. Ошибку 2). Уточняем через `silencedetect`
с порогом **между уровнями голосов**:

```bash
ffmpeg -hide_banner -i input.MOV -af "silencedetect=n=-34dB:d=0.25" -f null - 2>&1 \
  | grep -E "silence_(start|end)"
```

- `n=-34dB` — порог: выше подсказки (−39…−35), ниже автора (−27…−26)
- `d=0.25` — минимальная длина паузы, чтобы её засчитать

```python
def true_end(start, end):
    """первая тишина внутри сегмента = реальный конец речи"""
    for a, b in silences:
        if start < a < end:
            return a
    return end

st = max(0, seg["start"] - 0.10)          # 100 мс до — не срезать первый звук
en = true_end(seg["start"], seg["end"]) + 0.18   # 180 мс после — дать фразе «дозвучать»
```

**Что это даёт на практике:**

| Сегмент | ASR отдал | Реально | Экономия |
|---|---|---|---|
| 3 | 7.20–**13.60** | 7.10–**11.27** | 2.3 с тишины и захода подсказки |
| 19 | 51.46–**57.92** | 51.36–**55.27** | 2.6 с |

Без этой правки в ролик попадёт начало следующей реплики диктора — **именно так он
и «остаётся на фоне»**.

## 7. Шаг 5 — нарезка и склейка

Каждый фрагмент режется отдельно, с микро-фейдами на краях, иначе на стыках щелчки.

```bash
ffmpeg -v error -ss 7.10 -to 11.27 -i input.MOV \
  -af "afade=t=in:st=0:d=0.015,afade=t=out:st=4.155:d=0.015" \
  -c:v libx264 -preset fast -crf 16 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -avoid_negative_ts make_zero part00.mp4 -y
```

- `afade` 15 мс на входе и выходе — убирает щелчки на склейке
- `st` для `afade=t=out` = длительность фрагмента минус 0.015
- `-avoid_negative_ts make_zero` — иначе при concat поедут таймстемпы

Склейка:

```bash
# list.txt: file '/абсолютный/путь/part00.mp4'  (по строке на фрагмент)
ffmpeg -v error -f concat -safe 0 -i list.txt \
  -c:v libx264 -preset medium -crf 17 -pix_fmt yuv420p \
  -c:a aac -b:a 192k out.mp4 -y
```

> ⚠️ В `list.txt` только **абсолютные** пути и обязательно `-safe 0`.

## 8. Шаг 6 — контроль (не пропускать)

Проверять надо **программно**, а не на слух: тихий диктор на фоне легко не заметить.
Прогоняем финал через ту же диаризацию:

```bash
ffmpeg -v error -i out.mp4 -vn -ar 44100 -ac 1 -b:a 192k check.mp3 -y
curl -s -H "xi-api-key: $KEY" -F "model_id=scribe_v1" -F "diarize=true" \
  -F "language_code=hye" -F "file=@check.mp3" \
  https://api.elevenlabs.io/v1/speech-to-text -o check.json
```

```python
spk = sorted({w.get("speaker_id") for w in json.load(open("check.json"))["words"]
              if w.get("type") == "word"})
print(spk)   # должен быть РОВНО ОДИН: ['speaker_0']
```

Если голосов два — где-то не уточнена правая граница (Ошибка 2) или порог тишины
взят неверно (Ошибка 3).

Дополнительно проверить:
- транскрипт финала читается связно, без обрывов слов;
- пик не выше −3 dB, RMS около −18…−25;
- длительность = сумме фрагментов.

## 9. Если подсказка всё равно слышна фоном

Бывает, что подсказка звучит **одновременно** с автором (наушник фонит в микрофон).
Тогда нарезкой её не убрать — нужно разделение источников:

```bash
curl -s -o clean.mp3 -H "xi-api-key: $KEY" \
  -F "audio=@out.mp3" https://api.elevenlabs.io/v1/audio-isolation
```

Audio Isolation оставляет основной голос и вычищает фон. На нашем материале шумовой порог
падал с −34.7 до −53.3 dB, при этом громкость речи не менялась (−17.7 → −17.9 dB).

Проверка эффекта:

```bash
ffmpeg -hide_banner -i clean.mp3 -af astats -f null - 2>&1 | grep -E "RMS level dB|Noise floor dB"
```

## 10. Готовый скрипт целиком

```python
#!/usr/bin/env python3
"""Оставить в видео только речь автора, вырезав закадровую подсказку."""
import json, os, re, subprocess, sys

VIDEO = sys.argv[1]
OUT   = sys.argv[2]
LANG  = sys.argv[3] if len(sys.argv) > 3 else "rus"
WORK  = "work"; os.makedirs(f"{WORK}/parts", exist_ok=True)
KEY   = [l.split("=",1)[1].strip() for l in
         open(os.path.expanduser("~/Developer/video-use/.env"))
         if l.startswith("ELEVENLABS_API_KEY=")][0]

def sh(c): subprocess.run(c, shell=True, check=True)

# 1. диаризация
sh(f'ffmpeg -v error -i "{VIDEO}" -vn -ar 44100 -ac 1 -b:a 192k {WORK}/src.mp3 -y')
sh(f'curl -s -H "xi-api-key: {KEY}" -F "model_id=scribe_v1" -F "diarize=true" '
   f'-F "language_code={LANG}" -F "file=@{WORK}/src.mp3" '
   f'https://api.elevenlabs.io/v1/speech-to-text -o {WORK}/scribe.json')

ws = [w for w in json.load(open(f"{WORK}/scribe.json"))["words"] if w.get("type") == "word"]
segs, cur = [], None
for w in ws:
    s = w.get("speaker_id")
    if cur is None or cur["spk"] != s or w["start"] - cur["end"] > 1.2:
        cur = {"spk": s, "start": w["start"], "end": w["end"], "text": w["text"]}; segs.append(cur)
    else:
        cur["end"] = w["end"]; cur["text"] += " " + w["text"]

# 2. кто автор: громче + повторяет следом
def rms(a, b):
    o = subprocess.run(f'ffmpeg -hide_banner -ss {a} -to {b} -i "{VIDEO}" -af astats -f null -',
                       shell=True, capture_output=True, text=True).stderr
    m = re.search(r"RMS level dB:\s*(-?[\d.]+)", o)
    return float(m.group(1)) if m else -99
loud = {}
for spk in {s["spk"] for s in segs}:
    ss = [s for s in segs if s["spk"] == spk][:3]
    loud[spk] = sum(rms(s["start"], s["end"]) for s in ss) / len(ss)
AUTHOR = max(loud, key=loud.get)
print("громкость:", {k: round(v,1) for k,v in loud.items()}, "→ автор:", AUTHOR)
print("ПРОВЕРЬ ГУБЫ вручную перед продолжением (кадр в момент реплики каждого голоса)")

# 3. порог тишины между голосами
other = [k for k in loud if k != AUTHOR]
thr = int((loud[AUTHOR] + (loud[other[0]] if other else loud[AUTHOR]-12)) / 2)
o = subprocess.run(f'ffmpeg -hide_banner -i "{VIDEO}" -af silencedetect=n={thr}dB:d=0.25 -f null -',
                   shell=True, capture_output=True, text=True).stderr
sil, st = [], None
for line in o.splitlines():
    m = re.search(r"silence_start:\s*([\d.]+)", line)
    if m: st = float(m.group(1)); continue
    m = re.search(r"silence_end:\s*([\d.]+)", line)
    if m and st is not None: sil.append((st, float(m.group(1)))); st = None
print("порог тишины:", thr, "dB | пауз:", len(sil))

# 4. EDL автора + отсев фальстартов
def true_end(a, b):
    for x, _ in sil:
        if a < x < b: return x
    return b
mine = [s for s in segs if s["spk"] == AUTHOR]
edl, prev = [], ""
for s in mine:
    t = s["text"].strip()
    if prev and (t.startswith(prev[:14]) or prev.startswith(t[:14])) and len(t) > len(prev):
        edl.pop()                      # предыдущий был фальстартом
    if len(t) < 6 and s is mine[-1]:   # техническая реплика в конце
        continue
    edl.append({"start": max(0, s["start"] - 0.10),
                "end": true_end(s["start"], s["end"]) + 0.18, "text": t})
    prev = t
print("фрагментов:", len(edl), "| итого:", round(sum(e["end"]-e["start"] for e in edl), 1), "с")

# 5. нарезка и склейка
paths = []
for n, e in enumerate(edl):
    p = os.path.abspath(f"{WORK}/parts/p{n:02d}.mp4"); d = e["end"] - e["start"]
    sh(f'ffmpeg -v error -ss {e["start"]} -to {e["end"]} -i "{VIDEO}" '
       f'-af "afade=t=in:st=0:d=0.015,afade=t=out:st={d-0.015:.3f}:d=0.015" '
       f'-c:v libx264 -preset fast -crf 16 -pix_fmt yuv420p -c:a aac -b:a 192k '
       f'-avoid_negative_ts make_zero "{p}" -y')
    paths.append(p)
with open(f"{WORK}/list.txt", "w") as f:
    for p in paths: f.write(f"file '{p}'\n")
sh(f'ffmpeg -v error -f concat -safe 0 -i {WORK}/list.txt -c:v libx264 -preset medium '
   f'-crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k "{OUT}" -y')

# 6. контроль
sh(f'ffmpeg -v error -i "{OUT}" -vn -ar 44100 -ac 1 -b:a 192k {WORK}/check.mp3 -y')
sh(f'curl -s -H "xi-api-key: {KEY}" -F "model_id=scribe_v1" -F "diarize=true" '
   f'-F "language_code={LANG}" -F "file=@{WORK}/check.mp3" '
   f'https://api.elevenlabs.io/v1/speech-to-text -o {WORK}/check.json')
spk = sorted({w.get("speaker_id") for w in json.load(open(f"{WORK}/check.json"))["words"]
              if w.get("type") == "word"})
print("голосов в результате:", spk, "←", "ЧИСТО" if len(spk) == 1 else "ОСТАЛСЯ ЛИШНИЙ")
```

Запуск:

```bash
python remove_prompter.py input.MOV out.mp4 hye
```

> Скрипт определяет автора по громкости автоматически, но **проверку по губам надо сделать
> глазами** — это единственная проверка, которая не ошибается. Если автор говорит тише
> подсказки (редко, но бывает), поправь `AUTHOR` вручную.

## Короткий чек-лист

1. Диаризация с `diarize=true` — **без неё ничего не выйдет**
2. Определить автора **тремя** проверками, губы решающие
3. Порог тишины — **между** уровнями голосов
4. Правую границу каждого сегмента уточнить по `silencedetect`
5. Выбросить фальстарты и техническую болтовню
6. Микро-фейды 15 мс на стыках
7. Финал прогнать через диаризацию — должен остаться **один** голос
8. Если подсказка звучит одновременно — Audio Isolation
