# Reels Pro — скилл для Claude Code

**Что это.** Скилл, который превращает сырое видео в готовый к публикации вертикальный ролик
(Reels / TikTok / Shorts) — без ручного редактора вроде CapCut или Premiere.

Claude читает исходник, сам разбирает речь, вырезает лишнее, заменяет фон, расставляет титры
и графику, сводит звук и рендерит финал. Монтаж описывается спецификацией `spec.json`,
внешний вид переключается одной строкой — стилем.

**Зачем.** Ручной монтаж одного ролика занимает часы. Здесь тот же результат собирается
за минуты и повторяется на любом следующем видео без переделки.

## Установка как скилл

```bash
git clone https://github.com/Gor1x1/reels-pro ~/Developer/reels-pro
ln -sfn ~/Developer/reels-pro ~/.claude/skills/reels-pro
```

Дальше в Claude Code достаточно попросить смонтировать видео — скилл подхватится сам.
Инструкции для агента — в [SKILL.md](SKILL.md).

## Что умеет

| Этап | Инструмент |
|---|---|
| Разбор речи, отделение диктора от закадровой подсказки | ElevenLabs Scribe (диаризация) + анализ громкости + проверка по губам |
| Точная нарезка по границам речи | `silencedetect` с порогом выше уровня подсказки |
| Замена фона | RobustVideoMatting (AI-матирование) — работает там, где хромакей рвёт лицо |
| Чистка звука | ElevenLabs Audio Isolation + компрессия + `loudnorm -14 LUFS` |
| Субтитры | пословная разметка, караоке-подсветка, армянский / русский / латиница |
| Графика и движение | акцентные титры, уголки-скобки, боке, бейдж, зумы по смыслу |
| Сборка и рендер | Remotion |

## Стили

Один и тот же ролик собирается в любом из четырёх стилей — меняется `"style"` в спецификации.

| id | Когда использовать |
|---|---|
| `warm-studio` | тёплый интерьер, спокойный премиум, экспертный тон |
| `bold-orange` | высокая динамика, крупные капсы, хайповые темы |
| `clean-minimal` | деловой тон, ничего лишнего: без скобок, боке и бейджа |
| `neon-night` | тёмный кадр, свечение, техно- и AI-темы |

Эмодзи выключены во всех стилях по умолчанию — они удешевляют картинку.

Посмотреть все стили сразу:

```bash
npx remotion studio
# композиции Style-warm-studio, Style-bold-orange, Style-clean-minimal, Style-neon-night
```

## Быстрый старт

```bash
npm i
npx remotion studio          # предпросмотр
npx remotion render Reel out/reel.mp4 --crf=17
```

Материалы кладутся в `public/`: `main.mp4` (говорящий), `bg.png` (фон), `music.mp3`.
Субтитры — `src/captions.json`, сценарий — `src/spec.json`.

## Спецификация ролика

```jsonc
{
  "style": "warm-studio",
  "lang": "hy",                       // ru | hy | en — от этого зависит шрифт
  "video": "main.mp4",
  "background": "bg.png",
  "music": "music.mp3",
  "musicVolume": 0.07,
  "brand": { "badge": "GTH", "name": "ԳՈՌ", "role": "GTH LAB" },
  "scenes": [
    { "type": "hook", "dur": 72, "title": "GTH LAB", "subtitle": "AI AGENT LAB" },
    {
      "type": "speaker",
      "dur": 900,
      "zooms":   [[0, 1.04], [5.6, 1.1], [20.3, 1.12]],   // [секунда, масштаб]
      "punches": [{ "at": 6.0, "dur": 62, "line1": "GTH", "line2": "LAB" }],
      "nameAt": 24.0
    },
    { "type": "broll", "dur": 90, "src": "screen.mp4", "isVideo": true, "label": "DEMO" },
    { "type": "cta", "dur": 90, "line1": "ՀԵՏԵՎԻՐ", "line2": "ԱԼԻՔԻՆ", "button": "GTH LAB" }
  ]
}
```

Типы сцен: `hook` · `speaker` · `broll` · `cta`.

## Замена фона

```bash
python pipeline/matte.py \
  --video raw.mp4 --bg bg.png --out composited.mp4 \
  --grade "0.82,0.76,0.66" --exposure 0.92
```

Важное отличие от наивной реализации — **безопасное кадрирование** (`--fit auto`, включено по
умолчанию). Если человек в исходнике обрезан краем кадра (руки уходят за границу), уменьшать его
нельзя: срез уезжает внутрь кадра и получается «обрубок». Скрипт измеряет касание альфы к краям
и сам не даёт этого сделать:

```
разведка кадра: касание краёв left, right, bottom
  ! человек обрезан слева и справа — масштаб 0.88 показал бы срез, поднимаю до 1.0
```

Чтобы всё-таки показать больше фона — двигают фон (`--bg-zoom`, `--bg-dx`), а не уменьшают человека.

Другие ключи: `--despill` (снятие зелёного отлива), `--shrink` (подрезка кромки),
`--lightwrap` (свет фона на краях), `--feather` (мягкое затухание у срезанных краёв),
`--grade` / `--exposure` (подгонка под освещение фона).

## Шрифты

| Файл | Языки |
|---|---|
| `Montserrat-Black.ttf` | латиница + кириллица |
| `NotoArm.ttf` | латиница + армянский |
| `Anton-Regular.ttf` | латиница |

Системные SF Pro и Georgia армянский не отрисовывают, Anton не знает кириллицы — шрифт
выбирается автоматически по полю `lang`.

## Требования

Node.js 18+, Python 3.9+, ffmpeg. Для матирования — модель
[RobustVideoMatting](https://github.com/PeterL1n/RobustVideoMatting) (`rvm_mobilenetv3_fp32.onnx`).
Для транскрипции и чистки звука — ключ ElevenLabs.
